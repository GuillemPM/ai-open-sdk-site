This tutorial gets you from zero to a validated JSON response using AI Open SDK.

## 1. Add the dependencies

Reference **AI Open SDK** (core) and a provider extension such as **AI Open SDK Anthropic** from [GuillemPM/AL-AI-Toolkit](https://github.com/GuillemPM/AL-AI-Toolkit). Compile against Business Central Application 28.x.

See [Providers](/docs/providers) for the full packaging model.

## 2. Store the API key as SecretText

Load keys from Isolated Storage or a setup table into `SecretText` so the debugger never shows them.
