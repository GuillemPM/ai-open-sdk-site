---
title: AIOS Schema
description: Build JSON Schema for structured output.
---

`"AIOS Schema"` builds JSON Schema objects used with `Request.SetOutput(...)`.

Common helpers:

- `String()`, `Number()`, `Boolean()`, ...
- `Field(Name, Schema)`
- `Object(Fields)`
