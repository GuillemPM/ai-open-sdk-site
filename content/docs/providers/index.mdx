AI Open SDK splits into a **core** library and **provider extensions**. Your app depends on core plus only the providers you call. Swapping providers is a dependency and factory change; callers keep using `"AIOS Client"` and `"AIOS Language Model"`.

## Packaging

| App | Role |
|---|---|
| **AI Open SDK** | Core: `"AIOS Client"`, schema, tools, interfaces, `"AIOS Mock"` |
| **AI Open SDK Anthropic** | `"AIOS Anthropic"` → Claude text models |
| **AI Open SDK OpenAI** | `"AIOS OpenAI"` → chat and image models |
| **AI Open SDK OpenCode Zen** | `"AIOS OpenCode Zen"` → Zen gateway |
| **AI Open SDK OpenAI Compatible** | `"AIOS OpenAI Compatible"` → any Chat Completions base URL |
| **AI Open SDK Provider Utils** | Shared Chat Completions helpers (pulled by some providers; not for app code) |

Each provider extension depends on **AI Open SDK** (core). OpenAI, OpenCode Zen, and OpenAI Compatible also depend on Provider Utils. Your extension depends on core and on each provider app you install.

Use the published App Ids from AppSource or your symbol feed. Install only the provider apps you need.

## Capabilities

| Extension | Factory | Text | Image |
|---|---|---|---|
| AI Open SDK (core) | `"AIOS Mock"` | Yes | Yes |
| AI Open SDK Anthropic | `"AIOS Anthropic"` | Yes | No |
| AI Open SDK OpenAI | `"AIOS OpenAI"` | Yes | Yes |
| AI Open SDK OpenCode Zen | `"AIOS OpenCode Zen"` | Yes | No |
| AI Open SDK OpenAI Compatible | `"AIOS OpenAI Compatible"` | Yes | No |

## How a provider plugs in

1. The provider app implements `"AIOS Provider"` and returns `"AIOS Language Model"` (and `"AIOS Image Model"` when supported).
2. Your code calls `Factory.Model(...)` (or `ImageModel(...)`) and passes the model into `"AIOS Client"`.
3. API keys use `SecretText` end to end.
