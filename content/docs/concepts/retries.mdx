---
title: Retries
description: Configure retries for temporary provider failures.
---

The SDK can retry temporary provider failures before returning an error. Configure the limit on the request:

- `GetMaxRetries` / `SetMaxRetries` (default **2**)

Retries cover temporary failures such as:

- Rate limit
- Timeout
- Provider unavailable

The default is suitable for most calls. Lower it for interactive pages where a quick error is preferable, or raise it for background jobs where a temporary provider failure should be tolerated.
