`"AIOS Mock"` ships in **AI Open SDK** (core). It is an in-memory provider for text and image generation: no HTTP and no API keys.

Use it in automated tests and local development to keep AI-dependent code deterministic.

With Mock you can test:

- Run tests without secrets or network access
- Keep failures reproducible
- Structured output and tool loops without a live provider

## Setup

1. Depend on **AI Open SDK** (core).
2. Queue the response, error, or tool call you want to test.
3. Bind `Mock.Model(...)` or `Mock.ImageModel(...)` and call `"AIOS Client"`.

The queued response comes back verbatim, which is what makes assertions stable:

```text
Hello from mock
```

So the test asserts on a known value rather than on whatever a live model happened to say:

```al
Assert.AreEqual('Hello from mock', Result.Output(), 'Unexpected output');
```

Image: `Mock.SetNextImageBase64(...)` then `Client.GenerateImage(Mock.ImageModel(...), ...)`.

For tool-loop tests, `SetNextToolCallThenResponse` queues a tool call followed by a final response. See [Mock provider](/docs/providers/mock) for the available test responses.
