# AI Open SDK Site

Official website for **AI Open SDK**, the provider-agnostic AI library for Microsoft Dynamics 365 Business Central.

## Pillars

- **Product**: `/` introduces the SDK
- **Docs**: `/docs` is the reference (Fumadocs)
- **Learn**: `/learn` for tutorials and release notes

## Develop

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

SDK source: [GuillemPM/AL-AI-Toolkit](https://github.com/GuillemPM/AL-AI-Toolkit).

## Agent workflow

Cursor agents should follow [AGENTS.md](AGENTS.md) (docs-first). Project rules, skills (`write-docs`, `add-doc-page`, `review-docs`), and hooks live under `.cursor/`.
